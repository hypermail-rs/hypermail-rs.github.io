# Documentation Directory

This directory contains the source files for the hypermail-rs website.

## Structure

- `index.html` - Main website (handcrafted, committed to git)
- `api-docs/` - API documentation (generated by CI, **not** committed to git)

## Building Documentation

The API documentation is automatically built and deployed by the GitHub Actions workflow:

```bash
# Build API docs locally
RUSTDOCFLAGS="--html-in-header .rustdoc-header.html" cargo doc --no-deps
cp -r target/doc/* docs/api-docs/
```

## Deployment

On every push to `main`, the `.github/workflows/pages.yml` workflow:

1. Builds API documentation from Rust source code
2. Copies it to `docs/api-docs/`
3. Deploys entire `docs/` directory to GitHub Pages

## Local Preview

```bash
# Build docs
make docs  # or the cargo doc command above

# Preview with Python
python3 -m http.server 8000 --directory docs

# Open http://localhost:8000 in browser
```

## Notes

- `api-docs/` is in `.gitignore` - do not commit generated docs
- Website styling in `index.html` matches API docs via `.rustdoc-header.html`
- WCAG AA accessible (12.24:1 contrast ratio in sidebar)
